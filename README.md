# KAGEURI — THE LOST SCOUT (ENDLESS STAGES)

A free, local browser game built from the supplied KAGEURI Lost Scout project.

## What changed in this final correction

- Endless progression: the game no longer stops after five environments.
- The five environments cycle forever as Stage 1, Stage 2, Stage 3... with the stage number continuing upward.
- Stage duration increases by 30 seconds each stage: 1:00, 1:30, 2:00, 2:30, 3:00, 3:30...
- Enemy count increases every stage.
- Enemies also become larger and faster as stages progress.
- The player's movement pace increases with each stage.
- The relic system remains continuous: collected relics are replaced while the stage is active.
- The previous Wild Energy / bonus pickup has been removed completely.
- Bomb hazards are introduced from Stage 2 onward. They appear with a visible countdown and danger radius; later stages can have more hazards.
- Stage transitions happen automatically after a successful stage, so the run can continue endlessly.
- Score carries forward across the entire run.
- Scouts remain optional bonus objectives while the timer is the main stage-clear condition.
- Environments keep changing in a repeating Forest → Jungle → Desert → Ice → Deadland cycle.
- No wallet, login, payment, backend, or external library is required.

## Controls

- WASD / Arrow Keys — move
- Space — attack
- E — recover a nearby scout
- Shift — slower precision movement
- Touch controls are available on supported screens.

## Run

Extract the ZIP and double-click `index.html`.

The four supplied KAGEURI character artworks remain in `assets/`.
